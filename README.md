## Ejecución

### Método #1 (Fácil)
Descargue el ejecutable desde [itch.io](https://abbonexcore.itch.io/houtou). Ejecutelo y juegue!

[![Available on itch.io](http://jessemillar.github.io/available-on-itchio-badge/badge-bw.png)](https://abbonexcore.itch.io/houtou)

### Método #2
- Clone el repositorio con `git clone https://github.com/ivnmansi/HOUTOU`
- Ejecute `HOUTOU.exe`, dentro de la carpeta `build`

## Compilación
Si desea compilar el proyecto por su cuenta
- Instale Allegro 5 y mingw32 (windows) en su sistema
- Clone el repositorio con `git clone https://github.com/ivnmansi/HOUTOU`
- Ejecute el comando `mingw32-make folders`, de tal forma que se cree el directorio `obj`
- Ejecute el comando `mingw32-make`
- El ejecutable compilado se encontrará en la carpeta `build`
